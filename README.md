## 📖 About this application

WinSCP-Client helps you move files between your local computer and a remote server. It uses secure protocols to protect your data during the transfer. This software works on Windows 10 and Windows 11. You can use it to manage files on web servers, cloud storage, or private office servers. It works like a standard Windows folder window but allows access to distant systems.

## ⚙️ System requirements

Before you install this software, check your computer for these requirements:

- Operating system: Windows 10 or Windows 11.
- Processor: Any modern Intel or AMD processor.
- Memory: At least 2 gigabytes of RAM.
- Storage: 100 megabytes of free space on your hard drive.
- Internet connection: An active network connection to reach your remote server.

## 🚀 Setting up a connection

Once the program opens, you must connect to your remote server. Follow these steps to log in:

1. Locate the Login window when you open the application.
2. Select a file protocol from the File protocol dropdown menu. Use SFTP if you want high security.
3. Enter the Host name of the server in the Host name field.
4. Type your username and password into the marked boxes.
5. Click the Login button to start the connection.
6. A box might appear asking you to verify the server identity. Click Yes if you trust the server.

## 📂 Managing your files

The main screen shows two panels. The left side displays files on your computer. The right side shows files on the remote server. 

### Moving files
To move files from your computer to the server:
- Select the file on the left side.
- Drag the file to the right side.
- Drop the file into the folder you want.

To move files from the server to your computer:
- Select the file on the right side.
- Drag the file to the left side into your chosen local folder.

### Renaming and deleting
You can change file names or remove items by right-clicking them. A menu appears with options to Rename or Delete. Use caution when you delete files because the software removes them from the server permanently.

## 🔐 Security features

This client focuses on data safety during every transfer. It uses encryption keys to scramble data. This prevents unauthorized people from reading your files while they travel across the internet. You can save your session information to avoid typing your password every time. If you use this feature, the program stores your credentials in an encrypted format on your machine.

## 🛠 Troubleshooting common issues

If you face problems, check these items:

- Password errors: Ensure you typed your username and password correctly. Account details are case-sensitive.
- Connection timeouts: Check your internet connection. Some servers block connections if you take too long to log in.
- Permission denied: You might need specific rights to edit or move files in a folder. Contact your system manager if you lack access to a specific folder.
- Firewall settings: Sometimes, Windows Firewall blocks incoming or outgoing connections. Ensure that the program has permission to access the network.
